Methodology

Momentum (12-1) — 50%

Return from t-252 to t-22, skipping the last month to avoid short-term reversal. Z-scored across the universe.

Quality (Sharpe) — 30%

Annualized mean daily return / annualized daily vol, trailing 252 days. Gross Sharpe, rf = 0. Z-scored.

Low Volatility — 10%

Inverse z-score of annualized realized vol, trailing 252 days. Lower vol = higher score.

Low Drawdown — 10%

Inverse z-score of max drawdown from peak, trailing 252 days. Smaller drawdown = higher score.

Data source: Yahoo Finance (via yfinance), auto-adjusted daily closes, trailing ~3 years.
Universe: 96 liquid US mega-cap names across tech, semis, industrials, energy, and consumer.
Reproducibility: Fully deterministic given the same input data. Run the script and verify every number.
